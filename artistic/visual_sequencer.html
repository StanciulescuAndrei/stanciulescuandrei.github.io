About This Project

The "Visual Sequencer" explores generative sound using a modular system built within VCV Rack. The core essence of the project is a system that receives control voltage (CV) inputs to output a coherent melody driven entirely by those inputs. Rather than using preprogrammed sound, the project achieves its generative audio by pulling data from a TouchDesigner patch with synchronized visuals. By utilizing color data from an image, the project successfully establishes a clear relationship between visual source data and the resulting generated sound.

The vision was to move away from preprogrammed audio. Instead, the intention was to reinforce the relationship between the source of the data, in this case, an image and a moving rectangle, and the resulting sound it produces. Recently, I became very interested in sound synthesis and modular systems, so in this project, I wanted to explore how they can be used in generative audio sequences. In its most raw form, this is a tool for audio creation, to discover new sequences and interesting evolving patterns. It can also be adapted to an installation that reacts to the live environment to further increase its interactivity and sonic possibilities.

Process

Recently, I became very interested in sound design through sound synthesis, so for this final project, I wanted to explore generative sound using a modular system in VCV Rack. The main idea was that the system would receive some inputs as control voltage (CV) and then output a somewhat coherent melody, which is driven by those inputs. These inputs can come from any source, but in this case, I used a TouchDesigner patch with synchronized visuals to further reinforce that there is a relationship between the source of the data, in this case, the image and the moving rectangle, and the sound, instead of the sound being preprogrammed.

Melody

The VCV system takes as input 3 sources, which will drive 3 oscillators. Because the input can take any value, we need to quantize it to a scale, then shift it down if necessary, and plug it into the oscillator. Since we have 3 notes playing, two of them will be shifted to lower octaves to take up different frequency spaces. The oscillator output is then passed through a filter and then a Tape Delay module that adds some warmth and color to the sound. There are two envelope generators controlling this part, one for the VCA, where, by controlling the input gate length, you can get longer or shorter notes, and another similar EG that controls the filter cutoff frequency (which adds some more dynamics to the sound and mimics an almost “percussive” attack).

Rhythm

To accompany the melody, I wanted to create the percussion in the same module. There are only two sounds, a kick and a cymbal sound. The kick plays every beat while the cymbal plays on the 2 and 4. The kick is built from an oscillator and a noise source, both with very short envelopes. A second envelope is used to quickly reduce the oscillator frequency after the initial attack to create a punchier sound. This then goes through a Tape Machine and a Delay. For the cymbals, we use a noise source through a filter where an envelope controls the cutoff to reduce the initial brightness. The same envelope also controls the CV input of a wavetable VCO where I selected a noisy waveform. This is then mixed with the kick and passed to the final output mixer. The timing of the drums is controlled from an external clock source, and to only trigger the cymbals on the 2 and 4, I used a sequencer, but a more elegant version would have been to use a simple clock divider that outputs one pulse for every 2 input pulses.
